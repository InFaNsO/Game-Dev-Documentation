Production & Tier Economics

Art is near-free (one rig + corruption shader). The real budget is moveset animation + telegraph design — so the expensive multi-phase tier is held to nine, and growth lives in the cheap regular tier.

Cost per tier

  • Regular — 2–3 attack clips + shared idle/hit/death · 2–3 SOAttackDef · 1 SOFighterDef · animator graph · prefab. Pure data + clips.
  • Miniboss — 4–6 clips · phase-swap data · ≥1 feint branch. Needs the phase system + feint data model.
  • Boss — 6–8 clips · 3 phases · one set-piece mechanic (The Hold / off-screen angles / Escalation).

Mesh status

  • Amphibian (Jal) — exists.
  • Reptile (Agni) — exists (CinderScale).
  • Avian (Vayu) — the one new mesh; validate via the Art Bible first-slice rule before batch-producing Vayu.
  • Accessories + corruption shader differentiate silhouettes within a species.

Build order

Agni→ Jal→ Vayu
  • Agni first — CinderScale already leads it, the cheapest path to a full stratum for run-spine testing.
  • Vayu last — carries the only new-mesh pipeline risk.

Infra dependencies

  • Phase system — HP-threshold moveset swap (all 9 multi-phase enemies).
  • NPCAttackPlanner upgrade — signature spine + variable holds + difficulty-scaled chains.
  • Feint branch data — switch/cancel authored per the Reaction & Feints spec.
  • Ranged projectile + deflect-back — 7 of 15 enemies use projectiles.
  • Displacement / dart support — Vayu telegraph-displacement.
